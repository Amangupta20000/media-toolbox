NATIVEMEDIA AGENT — macOS FIRST LAUNCH

The current macOS release is not Apple-notarized. macOS may show a warning that it cannot verify “NativeMedia Agent.app”.

1. Open NativeMedia Agent.app once from the Applications folder.
2. If macOS shows the warning, click Done.
3. Open System Settings, then Privacy & Security.
4. In the Security section, click Open Anyway for NativeMedia Agent.app.
5. Confirm Open.

This approval is normally needed only once for a fresh full installation. Future launches and in-app updates use the existing update flow.

UPGRADING FROM AN OLDER VERSION

NativeMedia Agent stays running in the menu bar after its dashboard closes. Before replacing an existing app from a DMG, choose Quit NativeMedia Agent from the menu-bar menu. Then drag the new app into Applications, choose Replace, and launch it from Applications. This prevents macOS from reopening the older process that was still running during the copy.

Newer releases also detect an app-bundle replacement and restart after the copy, but quitting first is recommended for unsigned DMG upgrades.
