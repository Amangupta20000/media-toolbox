NativeMedia Agent Privacy Policy

Last updated: 12 September 2026

This policy explains how the NativeMedia Agent desktop app handles information when you use local processing.

Local processing

Files selected for Local Agent processing stay on the computer running the agent. The agent stores source files and temporary processing files in its local application-data directory while a job is running. Temporary files are cleaned up according to the job retention setting.

Results and history

If you choose to keep a result, the final file and the related job metadata remain in the agent's local Results folder until you delete them. If you choose delete-after-download, the source, intermediate files, output, and metadata are removed according to the agent's cleanup behavior.

Browser connection

The website communicates with the Local Agent through a loopback connection on this device. The agent uses short-lived browser session tokens and trusted website origins. Admin passwords and activation codes are handled by the desktop agent and are not sent to the website.

Information we do not collect

The Local Agent does not include analytics or advertising tracking. It does not upload local files to a remote service during Local Agent processing. Links to releases or support pages may open your browser only when you choose them.

Your control

You can end browser sessions, log out Admin access, delete retained results, and uninstall the agent. Uninstalling may not remove files you explicitly kept outside the agent's temporary folders; check the Results folder before removing application data.
